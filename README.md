# PythonSteg
A steganography application written in Python.


GUI Framework: PyQt5
Image Processing: OpenCV, scikit-image, PILLOW
Scientific Computing: NumPy, SciPy
3D Processing: PyOpenGL, trimesh


Encryption: 
  Noise-Based Embedding 
  DCT Frequency Embedding 
  Chaotic Map Embedding 
  RGBA Channel Embedding 
  Topological 3D Steganography

Analysis Tools: 
  Structural Similarity (SSIM) 
  Histogram Analysis 
  Bit Error Rate Calculation 
  Approximate Entropy Analysis 
  Variance Analysis 
  Steganalysis Report Generation 
  LSB Analysis 
  Side-By-Side Comparison 
  Regular-Singular Group Analysis

Supported file types:
  Image Files
    .png, .bmp, .jpg, .webp, .bmp
  Object (3D) Files
    .obj (Wavefront)
  Text Files
    .sty, .txt, .json, .html, .docx, .pdf, .xlsx, .csv
